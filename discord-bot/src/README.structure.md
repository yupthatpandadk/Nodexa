# Structure

- `src/index.js`: Discord gateway and moderation event/command orchestration
- `src/store.js`: cases and warnings
- `src/policy.js`: staff/exemption/escalation policy
- `src/raid.js`: join-rate detector and lockdown
- `src/appeals.js`: appeal state
- `src/audit.js`: append-only audit
- `test/`: unit tests and synthetic fixtures
- `DEPLOY.md`, service file and Dockerfile: deployment
