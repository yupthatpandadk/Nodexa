# Test guild sequence

1. Start with AutoMod and Auto Lockdown disabled.
2. Verify bot online state and slash commands.
3. Test warn/warnings/timeout with disposable test members.
4. Verify Case-ID logs and optional DMs.
5. Enable one AutoMod engine at a time and verify exemptions.
6. Simulate joins below and above raid threshold.
7. Enable Auto Lockdown only after manual lock/unlock works.
8. Verify appeal persistence/review flow.
9. Only then promote the branch to stable main.
