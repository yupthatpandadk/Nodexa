# Nodexa v0.4 changelog

- Renamed the project from GamePanel to Nodexa.
- Added a one-line GitHub installer bootstrap.
- Added interactive Linux installer menu for Panel, Agent, combined install, status, update and uninstall.
- Added Laravel/React panel source and Go-based Nodexa Agent source.
- Added Docker lifecycle, logs, stats, file APIs and local tar.gz backup support.
- Added Nodexa systemd services, Nginx setup, MariaDB, Redis and Docker installation flow.
- Added responsive Nodexa dashboard branding.
- Added initial database schema for nodes, servers, allocations, backups, schedules, subusers and templates.

Nodexa is still a development preview and should be tested on a separate Ubuntu server before production use.
