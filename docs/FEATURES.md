# Nodexa feature roadmap

## User panel
Dashboard, server list, realtime status, console, power controls, resource graphs, file manager, SFTP, startup variables, network allocations, databases, schedules, users/subusers and granular permissions, backups, activity/audit log, account settings and API keys.

## Administration
Locations, nodes, allocations, users, servers, templates, variables, Docker images, mounts, database hosts, API credentials, system settings, mail settings, audit logs and maintenance tools.

## Nodexa Agent
Docker lifecycle, image pulls, resource limits, stats streaming, log streaming, stdin, file operations, archive extraction, backups, SFTP, install scripts, network management, crash detection, reinstall, transfer between nodes, disk checks and signed panel authentication.

## Security
Per-node tokens, TLS, short-lived websocket tokens, RBAC, audit log, 2FA, rate limits, encrypted secrets, container isolation, path traversal protection, checksum validation and configurable allowed Docker images.
